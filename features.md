# Claude Sentinel - Features

Claude Sentinel is a comprehensive desktop application designed to monitor Claude AI usage, manage auto-renewal sessions, and provide detailed analytics and reporting. Built with Electron, React, and TypeScript, it offers a modern, cross-platform solution for Claude users.

## 🚀 Core Features

### 1. **Real-time Usage Monitoring**

- **Live Dashboard**: Real-time tracking of Claude token usage, request counts, and estimated costs
- **Visual Analytics**: Interactive charts and graphs showing usage trends over time
- **Cost Estimation**: Automatic calculation of usage costs based on current token consumption
- **Session Tracking**: Monitor individual Claude sessions and their resource usage
- **Usage Predictions**: AI-powered predictions for future usage patterns

### 2. **Auto-Renewal Management**

- **Automatic Session Renewal**: Prevents Claude session timeouts by automatically renewing sessions
- **Configurable Scheduling**: Set custom renewal intervals and timing preferences
- **Smart Detection**: Monitors billing cycles and usage patterns for optimal renewal timing
- **Background Operation**: Runs unobtrusively in the system tray
- **Renewal Status Indicators**: Visual indicators showing renewal status and activity

### 3. **Cross-Platform Support**

- **macOS**: Native DMG and ZIP builds with ARM64 and Intel support
- **Windows**: NSIS installer and portable EXE formats
- **Linux**: AppImage and DEB package support
- **System Tray Integration**: Background operation with tray icon access

### 4. **Advanced Reporting & Analytics**

- **Detailed Reports**: Comprehensive usage reports with filtering and export capabilities
- **Historical Data**: Track usage patterns over time with date range selection
- **Log Viewer**: Access detailed application and renewal logs
- **Export Functionality**: Export reports in various formats for external analysis
- **Custom Date Ranges**: Analyze usage for specific time periods
- **Cross-Device Session Transfer**: Export and import Claude usage sessions between devices
- **Session Continuity**: Maintain session history when switching between computers

### 5. **Spec Development Suite** ⭐

- **AI-Powered Specification Generation**: Interactive development environment for creating technical specifications
- **Chat Interface**: Conversational AI for specification development
- **Markdown Preview**: Live preview of generated specifications
- **Project Management**: Organize specifications into projects and folders
- **Approval Workflow**: Review and approve generated specifications

## 🛠️ Technical Features

### 6. **System Integration**

- **ccusage Integration**: Seamless integration with Claude's usage tracking system
- **File System Access**: Direct access to Claude project data and usage files
- **Background Processing**: Efficient background workers for data processing
- **Notification System**: Smart notifications for renewal status and important events

### 7. **User Experience**

- **Modern UI**: Clean, responsive interface built with React and Tailwind CSS
- **Dark/Light Themes**: Adaptive theming with system preference detection
- **Keyboard Shortcuts**: Productivity-focused keyboard navigation
- **Floating Mode**: Compact floating window for minimal screen usage
- **Collapsible Sidebar**: Space-efficient navigation

### 8. **Developer-Friendly Architecture**

- **TypeScript**: Full type safety throughout the application
- **Modular Design**: Well-organized component and service architecture
- **State Management**: Zustand-based state management for predictable updates
- **IPC Communication**: Secure inter-process communication between Electron processes
- **Hot Reload**: Fast development with Vite's hot module replacement
